Game Text reads a target's C++ and config text (`@ue-shed/code`) and compares two points natively: `comparePoints` lists the lines a change adds, removes, rekeys or edits, and `localizationGateComparison` judges the change against the target's localization as the change found it, so only what the change introduces counts. Package editor text a target does not gather, by Unreal's gather table or else the audience policy, is left out of both points as the index leaves it out of scope, unless the base's manifest names it in that file. The gate result gains an optional `change` describing what a changelist check read. `readGameTextChangePoints` reads a submitted changelist, a shelf, a range of submitted changelists or listed working-copy files through revisions the host supplies, and the workspace's new `compareChange` method serves it to hosts that pass `changeRevisions`. Map History reads revisions at a changelist, across a range (`readRangeRevisions`), at the depot's head or the workspace's; `perforceChangeRevisions` hands those reads to Game Text; it uses a workspace the host names as named; it classifies Perforce failures by cause and refuses a changelist whose status is not the one asked for.
