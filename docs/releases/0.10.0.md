# UE Shed 0.10.0

UE Shed 0.10.0 lets live camera previews show editor-only spawn-volume previews, like captures
already do, and tells an open camera set apart from another render session. All 19 public npm
packages and ten Unreal plugins advance to 0.10.0 together; packages without direct changes advance
for suite alignment and exact dependencies.

## Live previews show editor-only previews

- `ensureProvisionedCameras` accepts opt-in `editorPreviews`. Its live previews then show the child
  actors that ChildActorComponents spawn for editor-only owners, such as spawn-volume previews,
  using the same rule as `renderer.editorPreviews` on renders. A host's live preview can match its
  captures, including while a camera set is open and render sessions are refused.
- The plugin rescans before each batch of preview frames and restores the original flags when the
  feed is cleared or reprovisioned without the option, when its world is cleaned up, when Play
  starts, and on shutdown. Saves never write the changed flag.
- Render sessions, camera panel previews and the live feed share one reference-counted reveal, so
  one of them finishing never hides a preview another still shows.
- Feed status and `getCameraStatus` report `editorPreviews.revealedChildActors` while the feed shows
  previews.

## An open camera set has its own refusal

- While a camera set is open in the editor, the renderer refuses a session with the new
  `authoring_open` code ("A camera set is open in the editor." / "Close the camera set, then
  retry."). `editor_busy` now means only another render session or an unrelated screenshot.
- Failures carry the blocking issue's recovery instead of generic advice, including Review and
  map-tile captures. Review capture reports both refusals as retry-safe view failures with the
  native message rather than a connection failure. `isEditorOwnershipRejection` identifies them.

## Upgrade notes

Install matching 0.10.0 packages and native plugins; Cameras changed natively.

- The provisioning request uses version 5 only when `editorPreviews` is on, so other requests are
  unchanged. Older plugins ignore the option, and `ensureProvisionedCameras` then fails with the new
  `ProvisionedCameraError` code `unsupported_capability`; retry without the option to fall back. A
  missing visibility echo (version 4) now carries the same code.
- Older plugins keep sending `editor_busy` for an open camera set. Packages before 0.10.0 don't
  recognise `authoring_open` and report it as `render_connection_failed`, so upgrade the package
  with the plugin.

Native plugin compatibility targets Unreal 5.7 and 5.8. Compiled variants require matching engine
version, BuildId, platform and architecture.
