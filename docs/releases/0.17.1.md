# UE Shed 0.17.1

UE Shed 0.17.1 adds the `UEShedGameText` editor plugin to the `editor-host` plugin bundle and
corrects the 0.17.0 migration documentation. All 20 public npm packages and twelve Unreal plugins
advance to 0.17.1 together; no npm package has a code change.

## Editor-host plugin bundle

- The `editor-host` bundle now includes `UEShedGameText` beside camera authoring and DataTable
  authoring, so a host that installs it can fix text keys in DataAssets, Blueprint defaults,
  widgets, graph pins and String Tables through Unreal. Its manifest records the
  `ue-shed-game-text-actions` 1.0 contract. In 0.17.0 the plugin shipped only in the full bundle.
- Every plugin must now belong to a bundle preset or be listed as full-bundle-only, so a new plugin
  can no longer be left out of the presets unnoticed. `UEShedAssetAudits` and `UEShedScenarios`
  remain full-bundle-only.

## Documentation

- The [migration guide](../engineering/effect-audit-migration.md) no longer recommends the removed
  TypeScript builder export or the `searchWorker` option, and names the native engine's protocol
  requirements.
- Package changelogs mark the TypeScript default builder and the search worker as superseded within
  0.17.0, and their migration-guide links resolve.
