# UE Shed 0.19.0

UE Shed 0.19.0 moves Game Text reports, gates and exports onto native index reads, adds exact
source and translation-key filters, and keeps interactive reads responsive during bulk exports.
All 20 public npm packages and twelve Unreal plugins advance together; packages without direct
changes advance for suite alignment and exact dependencies.

## Game Text index reads

- Filter exact source texts and every stored review signal. Group by source with a minimum group
  size to find text shared by several keys. Exact UTF-16 values survive filtered reads and exports.
- Aggregate matching rows by up to four dimensions, including culture and translation state, with
  line and word counts. Project selected localization fields without exporting complete records.
- Read corpus headers, bounded report diagnostics, named units and a cached corpus fingerprint.
- Reports, baselines, changed-file gates, CSV exports and investigations use the index directly.
- Indexed line and unit IDs speed up selections and focus. A separate bulk process keeps dumps
  from holding interactive searches; failed bulk-reader acquisition releases that process immediately.
- Localization reports read evidence once per evidence object and yield between evidence pages.
  Refresh spans expose stage timings, package import activity and worker utilization.

## Engine discovery and authoring

- Engine discovery includes the Launcher's Windows registry entries. Hosts can enumerate installed
  roots, resolve registered builds and supply a registry query for isolated tests.
- The `translation_key` filter selects the gathered namespace/key identity across saved package
  copies. `gatheredIdentityKey` produces its wire value.
- `UEShedAuthoring` initializes reflected struct properties when its editor module loads.

## Compatibility

Hosts implementing the Game Text query contract must supply its new index-read methods.
`TextCorpusReportHeader` and `textCorpusReportHeader` are public for those implementations.
Existing whole-input report functions remain available. Bulk reads may retain a second snapshot
reader and increase model memory; failure to open it uses the interactive reader.
