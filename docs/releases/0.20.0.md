# UE Shed 0.20.0

UE Shed 0.20.0 adds asset-type filters to Game Text, fixes text authoring on DataTables with User
Defined Structs, follows packages moved outside Unreal, and brings asset navigation and opening to
Unreal 4.27. All 20 public npm packages and twelve Unreal plugins advance together; packages without
direct changes advance for suite alignment and exact dependencies.

## Game Text: filter by asset type

- Search requests accept an `asset_type` clause with class paths such as
  `/Script/Engine.DataTable` or `/Script/UMGEditor.WidgetBlueprint`.
- `is` selects text with a saved place of a selected type; `is_not` selects text with none.
  The reader reports the main asset's class, or its world's class for an external actor package.
- `facets.assetTypes` counts matching lines by type, excluding the request's own asset-type filter.
  `textAssetTypeLabel` provides readable labels, and the Workbench filter menu lists those types.
- Native queries, paging, aggregates and exports use the same stored package classification.

## DataTable text fixes on User Defined Structs

- Key repairs and source edits bind a reviewed cell by its reflected property FName rather than
  assuming its authored display name identifies the property.
- Authoring snapshot 2.4 field descriptors expose `propertyName`, and `UEShedAuthoring` supplies it.
  Table edits send that FName through `set_cell`.
- A missing live column reports `TextIdTableColumnError`, including guidance when the editor's
  plugin predates the property-name evidence.

## Packages moved outside Unreal

- Package text records retain the saved `packageName` as evidence and resolve the package's own
  object, class and Blueprint class paths at the file's current location.
- References into other packages remain as saved. Opening a moved DataTable uses its current path.
- Package text shards advance to `package-text-v8`. Existing indexes re-extract packages on the next
  refresh to populate moved-path evidence and asset classifications.

## Asset navigation on UE 4.27

- The 4.27 Game Text bundle now includes a limited `UEShedCoreEditor`, enabling Show in Unreal,
  asset opening and window activation.
- The editor advertises `editor.asset-navigation.v1`, `editor.asset-open.v1` and
  `editor.window-activation.v1` only when their implementation is built.
- UE5 capability manifests retain their existing behavior. Play sessions, world control and
  foreground responsiveness remain UE5 capabilities.

## Compatibility

Use matching 0.20.0 packages and plugin sources for the new authoring field evidence and UE4 asset
navigation. The package text wire contract advances to uasset-io 1.17; authoring snapshots use 2.4.
The CLI and headless libraries expose the same filtering and authoring behavior as Workbench.
