# UE Shed 0.21.0

UE Shed 0.21.0 makes Game Text scans faster and its caches smaller, and Workbench reopens a saved
index at once. Game Text now keeps one unit per key Unreal translates and classifies problems from
one table. More saved Blueprint, Sequencer and Niagara data is decoded on UE 4.27 and UE5. Hosts
can configure Remote Control access, editor launches, localization audits and capture limits
without changing UE Shed. The CLI and Workbench gain Enhanced Input conflict analysis. All 20 public
npm packages and twelve Unreal plugins advance together; packages without direct changes advance
for suite alignment and exact dependencies.

## Game Text: faster scans, smaller caches, instant reopen

- Cold package text can skip the host's event stream. uasset-io 1.19 adds `staging` to
  `extract_text_packages`: the reader writes each package's record to a group file, and cold imports
  read and validate those files in their workers. `AssetReader.stageProjectTextPackages` and
  `GameTextIndexSource.stage` expose it.
- The native writer encodes a cold batch's layers concurrently and builds the full join with
  precomputed collation keys. Native build sessions reuse up to four writer processes.
- Large Blueprints and Niagara packages decode faster with identical output; a 32 MB Blueprint went
  from 4.6 s to 0.35 s.
- On a local UE 5.7 project of about 11,000 packages, a cold Workbench scan to usable results went
  from 19.8 s to 5.4 s.
- `GameTextIndexSteps.openCommitted` opens an already committed view without reading packages.
  The workspace's `configuredRefresh(false)` uses it and marks the result `cached: true`. A cached
  view can be browsed and searched; quality rules, operation targets and investigation exports wait
  until a refresh has checked it against the current Project Index.
- Workbench shows a saved index's results at once and rescans behind them. Results appeared 1.5 s
  after relaunch on the UE 5.7 project (from 2.2 s) and 3.1 s on a UE 4.27 project of about 167,000
  packages (from 8.4 s).
- Game Text cache columns use new zstd section codecs; the UE 5.7 project's cache shrank from
  19.4 MB to 8.3 MB. The Project Index Catalog is compressed (`catalogs-v6`); its snapshot shrank
  from 9.7 MB to 1.9 MB.
- Project Index status is answered by the reader's existing session instead of a new process.
- The native engine reports the ID index's load and build seconds separately in `stage_seconds`.

## Game Text: one unit per key, one problem table

- Units key resolved text by the namespace without its package marker, as gathered text does, so
  text saved under one key in several packages is one unit with all its places. String Table
  entries and references keep their keys.
- `TEXT_PROBLEM_RULES` says which states, facts, unknown reasons and review signals raise each
  problem. TypeScript and the native engine both classify from it, so filters, groups, aggregates
  and counts agree with the labels.
- The new `unchecked` problem ("Couldn't check") covers a culture in scope whose state the evidence
  cannot prove; up to date now means every culture in scope was confirmed.
- Findings follow the request. Search rows carry `problems` and `countedFindings`.

## More saved data decoded

- UE 4.27: editable node pin suffixes, soft object path structs, Blueprint class records, property
  GUID maps, numeric channels, Level Sequence binding maps, DataTable row handles saved without
  default fields, and Niagara variable records.
- UE5: graph pins from saved revisions 1000 to 1018, Blueprint class records, DynamicCast nodes,
  splines, Niagara variable records, field paths and newer numeric channel framing.
- uasset-io 1.18 adds `textGapCounts` to package text records and `may_contain_text` to gaps, so a
  partial read distinguishes text-free data from data that may hide text.

## Host configuration

- `makeRemoteControlClient` accepts a `passphrase` and extra `headers`. An editor's HTTP 401 reports
  a refused passphrase.
- Launches and supervised sessions accept `remoteControlAllowedClasses` for the UE 5.8 Remote
  Control allowlist. `readEngineInstallation` and a manifest `requestTimeout` are exported.
- `makeLocalizationOperationsLayer({ auditLimits })` sets the write audit's bounds.
  `localizationCarryChanges` and `GameTextIdRepairsApi` are public.
- World preparation takes a request timeout and lease options. `observatoryLayer` accepts the
  host's window activation.
- Limits that hosts copied are exported: the saved reader's request and Catalog timeouts, saved review and
  investigation file limits, map tile and Niagara preview limits, and Blueprint search hits.
  `@ue-shed/map-history/diff` is a browser-safe entry.
- New test layers cover editor activation and foreground checks, plugin distribution, localization
  operations, map capture and Observatory.

## Enhanced Input in the CLI and Workbench

- The scan reads the saved properties it used to skip, trigger and modifier parameters, and player
  mappable input config assets. A project with one no longer reports a false partial scan.
- Co-activation sets from the project's default contexts, config assets or a host document classify
  contested keys as shadowed, may shadow, both fire, ambiguous priority, qualified or cross-context,
  following Unreal's consumption and chord rules.
- `ue-shed input atlas`, `conflicts`, `unused`, `platforms` and `export` are new. The Input Atlas
  route gains a conflict-class filter and an in-project platform view.

## Fixes

- Workbench runs one Project Index refresh per project at a time, so a scan started during a warm
  open's background refresh waits instead of failing on the Catalog lock.
- The SQLite oracle Catalog drops a deleted sidecar's signature.

## Compatibility

Use matching 0.21.0 packages and plugin sources. The package text wire contract advances to
uasset-io 1.19. Existing caches rebuild once: the Catalog moves to `catalogs-v6`, Game Text caches
to `game-text-v2`, joined layers to `joined-native-v3` and package text shards to
`package-text-v9`. Unit IDs of text saved under one key in several packages change, so saved
selections by those IDs need their new ID. Enhanced Input schema 1 reports still decode.

  enabled live Unreal and Perforce integrations).
- Clean release pack: passed in 5m48s for all 20 public packages.
- UAsset engine matrix: passed in 8m15s on UE 5.7.4 and UE 5.8.3, with legacy generation passing on
  UE 4.27.2. UE 5.3 was unavailable and explicitly skipped.
- Live Unreal gate (`check:unreal`): passed in 5m10s; 33 tests passed, 0 skipped.
- Plugin compatibility: all 49 automation tests passed on each of UE 5.7.4 and UE 5.8.3, and the
  UE 4.27.2 Game Text bundle passed all 8.
- The merged pull requests were verified on Node 24.22 and 26.5 before this release.

Preparing the release fixed three gate problems, all in test harnesses rather than the shipped
packages. The Playwright trace test now isolates its temporary spec from an outer
`package.json`. The UE 4.27 plugin run no longer loads or rewrites the user's own editor layout. The
localization fixture keeps report steps that write one file in separate GatherText processes.
This preparation does not publish npm packages, release tags or a GitHub release.
