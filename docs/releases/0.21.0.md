# UE Shed 0.21.0

UE Shed 0.21.0 makes saved Game Text indexes faster to build and reopen, reduces cache sizes,
expands saved-package coverage, and exposes more configuration and composition APIs to hosts.
All 20 public npm packages and twelve Unreal plugins advance together; packages without direct
changes advance for suite alignment and exact dependencies.

## Game Text

- Reopen a committed index without scanning packages through `GameTextIndexSteps.openCommitted`.
  Workbench shows cached results immediately and refreshes in the background. Cached results remain
  searchable; quality checks, operation targets and investigation exports wait for a current scan.
- Cold imports stage package text directly to files, avoiding large records on the host event stream.
  Native writers encode layers concurrently, reuse processes between sessions, and report more
  detailed join and ID-index timings.
- Compact column codecs and compressed Project Index Catalogs reduce disk use. Existing caches
  rebuild once under `game-text-v2` and `catalogs-v6`.
- Resolved text shares one unit per namespace and key Unreal translates, retaining all saved places
  and their original namespace evidence. Multi-package keys receive new unit IDs; saved selections
  using their old IDs must be updated. Joined caches rebuild under `joined-native-v3`.
- A shared problem-rule table keeps TypeScript labels and native filtering, groups and counts in
  agreement. The new `unchecked` problem identifies culture states the evidence cannot prove.
  Missing project text counts as changed since gather, and counted findings follow the query.

## Saved-package coverage

- Decode more Blueprint, Sequencer and Niagara records on UE 4.27 and UE5, including graph pins,
  class records, numeric channels, binding maps, field paths and saved struct variants.
- Preserve coverage gaps while distinguishing text-free data from data that may hide text.
  Native and WASM text status use the same evidence.
- Large Blueprint graph membership is decoded once per owning export, and numeric text projection
  avoids unnecessary work.
- Project Index status uses the existing reader session, with a fallback for older readers.

## Host APIs

- Configure Remote Control passphrases and headers, manifest request timeouts, additional UE 5.8
  Remote Control classes, plugin bundle asset names, and localization audit limits.
- Read an engine installation directly from its root, configure world-preparation request timeouts,
  and receive lease identity and duration while working with a prepared world.
- Public limits, browser-safe diff helpers, localization carry-over, Blueprint search bounds and
  policy-resolution helpers let hosts compose workflows without copying internal code.
- Additional test layers cover engine activation, plugin distribution, compiled plugin builds,
  localization operations, Observatory and map capture.

## Input Atlas and CLI

Enhanced Input scan schema 2 retains more action, mapping, context, trigger and modifier evidence,
including Player Mappable Input Config assets. Schema 1 reports still decode. Co-activation evidence
supports conflict classification using Unreal's consumption and chord rules; without that evidence,
the report claims only contested keys. New `ue-shed input atlas`, `conflicts`, `unused`, `platforms`
and `export` commands accompany the route's conflict filter and platform view.

The development Game Text corpus generator now creates conflicting keys in Blueprint variables,
Blueprint pins and widget text, extending the existing DataTable conflict cases.

## Release tooling

After `pnpm release:prepare` passes, `pnpm release --checked` uses the recorded evidence without
rerunning checks. It still requires a clean release commit, current evidence and unchanged tarballs,
and asks for the exact publication phrase before contacting npm.

## Compatibility

Use matching 0.21.0 packages and plugin sources. uasset-io 1.19 adds staged text extraction after
1.18's text-gap evidence; older negotiated clients omit unsupported fields. Package text shards
advance to `package-text-v9` and re-extract once. Older readers cannot decode the new compact column
codecs. Public package Node requirements remain as declared in each package; repository release
tooling uses Node 26.
