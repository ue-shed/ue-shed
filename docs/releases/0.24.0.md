# UE Shed 0.24.0

UE Shed 0.24.0 reads what a change does. Game Text checks a Perforce changelist's text without a
workspace synced to it, compares two revisions of a localization file, and the asset reader
compares two saved revisions of a Blueprint. All 21 public npm packages and twelve Unreal plugins
advance together; packages without direct changes advance for suite alignment and exact
dependencies.

Every library change in this release is additive. The `ue-shed` CLI's exit codes changed; see
[the CLI section](#cli).

## Changelist text checks

- **New:** Game Text compares two points of a project natively. `comparePoints` lists the lines a
  change adds, removes, rekeys or edits, and `localizationGateComparison` judges the change against
  the target's localization as the change found it, so only what the change introduces counts.
- `readGameTextChangePoints` reads a submitted changelist, a shelf, a range of submitted
  changelists or listed working-copy files, through revisions the host supplies. The workspace's
  new `compareChange` method serves it to hosts that pass `changeRevisions`; without them it
  answers `capability_missing`. A change with a package or code file that could not be read
  answers `failed` with `unreadable_package` and the files, rather than a verdict that never saw
  them.
- Game Text reads a target's C++ and config text (`@ue-shed/code`) when the host passes
  `codeSource`; without it, code text shows from the gather manifest only.
- Package editor text a target does not gather is left out of both points, as the index leaves it
  out of scope. A text that only moved to another object of its package, keeping its key, text and
  property, is unchanged, since a Blueprint's generated functions renumber on compile; a text edited
  while its function renumbered is judged as an edit.
- The gate result gains an optional `change` describing what a changelist check read.
- A warm check of a changelist in a large UE 4.27 project takes 1.3–1.6 s.

## Map History

- **New:** Map History reads revisions at a changelist, across a range (`readRangeRevisions`,
  listing a long range's files in batches a Windows command line holds), at the depot's head or the
  workspace's. `perforceChangeRevisions` hands those reads to Game Text.
  `changelistRevisions` reads with a Perforce client the caller provides, and
  `readChangelistRevisions` still finds the project's workspace itself.
- It uses a workspace the host names as named, classifies Perforce failures by cause, and refuses a
  changelist whose status is not the one asked for.
- Revisions are printed 16 at a time, each batch written before the next, rather than holding a
  side's files in memory. Each Perforce server's revisions have their own cache folder, so two
  servers with the same depot path and revision never share bytes.

## Localization file comparison

- **New:** compare two revisions of a `.po`, `.archive` or `.manifest` file without a scan. The
  workspace's `chooseLocalizationFile` asks the person for each side through the host's file
  chooser, and `compareLocalizationFiles` compares only files chosen that way.
- The engine pairs entries by identity, then by occurrence, finds rekeyed texts, and sorts each
  change by what it means for the translations: a new key that lost its translation, changed
  wording, a case, punctuation or spacing change only, removed, added, a changed translation, a new
  key that kept its translation, or notes and references only. Filtering by group, text or asset
  and paging run in the engine, and each group lists its top assets.
- On a large UE 4.27 project's 67–78 MB files, about 133,000 keys each, the first page takes
  1.2–1.8 s and a later page or filter 1–2 ms.

## Blueprint comparison

- **New:** `compareBlueprintRevisions` (`@ue-shed/unreal-assets`) compares two saved revisions of a
  Blueprint without Unreal. It returns a page of the nodes, wires, variables, components and class
  defaults a change added, removed or changed. Graphs, nodes and pins pair by saved identity, so a
  moved or renumbered node is counted rather than listed.
- A node, definition part or component template one side could not read is counted as unread,
  not listed as removed or added. The result says what it did not compare: a widget's layout and
  animations, and timelines.
- It needs the reader's uasset-io v1.21 `compare_blueprints` request (`@ue-shed/protocol`).
- On 121 Blueprint and Widget Blueprint edits from a large UE 4.27 project, reading both sides took
  a median 12 ms and the diff 1.7 ms. On twelve of them (5,030 nodes), Unreal's own `DiffAssets`
  export agreed on every node added and removed and on every pin default changed. It differed by
  two changed nodes and two wires; each difference is explained in Plan 062.

## Unreal plugins

- **UEShedAuthoring:** Apply tells open DataTable editors about its changes, so an open table
  shows applied or restored rows without another edit. The `UEShed.Authoring.EditorNotifications`
  automation test checks a cell edit, an added row and a rolled-back Apply.

## CLI

The `ue-shed` CLI is not published to npm; it ships with the repository.

- `ue-shed loc gate --change <CL>`, `--shelved <CL>` and `--from <CL> --to <CL>` check a Perforce
  change's text without a workspace synced to it. `ue-shed loc diff` lists what a change does to
  lines and translations without a verdict. Both print `--format json`, `text` or `markdown`, and
  `ue-shed guide changelist-check` prints a guide for coding agents.
- **Breaking for scripts:** every CLI failure exits by its error's next step: `2` could not run,
  `3` may succeed if repeated (such as Perforce being unavailable), `4` an internal crash (formerly
  `1`, which now only ever means a failed check), `130` interrupted.

## Compatibility

Use matching 0.24.0 packages and plugin sources. The UEShedAuthoring change rebuilds that plugin.
Blueprint comparison needs the 0.24.0 reader (`@ue-shed/uasset-win32-x64`). Public package Node
requirements remain as declared in each package; repository release tooling uses Node 26.

- Plugin compatibility on UE 5.8: passed in 57s.

Preparation found three problems, each fixed before these runs:

- On Windows, clippy rejected the Game Text engine's queue of parsed requests as one large enum.
  Boxing them changed the engine's contract hash, which was then regenerated.
- The Data Authoring kit's copy list lacked protocol's `blueprint-diff.ts`, the UI package's text
  diff and the `unreal-code` crate.
- Five package changelogs had empty 0.24.0 sections.

No packages or release tags have been published.
