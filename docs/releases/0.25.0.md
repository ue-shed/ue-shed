# UE Shed 0.25.0

UE Shed 0.25.0 makes the asset reader faster. Game Text cold builds take about 40% less time, and
the WASM runtime can parse a package once for several reads. All 21 public npm packages and twelve
Unreal plugins advance together; packages without direct changes advance for suite alignment and
exact dependencies.

Every library change in this release is additive.

## Asset reader

- The native reader decodes property streams faster and with about 40% less peak heap. A host can
  choose which top-level properties a decode materializes, and native text extraction decodes only
  properties that can hold text.
- Text, places and text-capable gaps are unchanged. Coverage gaps that cannot hold text are no
  longer reported, and some exports that failed to decode now decode.
- The reader allocates with mimalloc, reuses each thread's compression contexts, and release
  binaries are built with fat LTO.

## Game Text

- Cold builds are about 40% faster. On a large UE 4.27 project, the median cold build took
  31.3 s, down from 53.9 s.
- Localization manifests and archives are parsed in one pass, with byte-identical columns and
  diagnostics.

## WASM runtime

- **New:** `runtime.openPackage(path, bytes)` returns a handle that parses a package once and
  serves `inspect`, `extractText`, `extractTextures`, `extractAuthoringTable`,
  `extractLevelSequences`, `extractBlueprints` and `extractAnimations`, with the same results as the
  per-call methods. `free()` releases it.
- Inspecting through one handle is 13–33% faster.

## Unreal plugins

No plugin source changed; the plugins advance to 0.25.0 for suite alignment.

## Compatibility

Use matching 0.25.0 packages and plugin sources. Public package Node requirements remain as
declared in each package; repository release tooling uses Node 26.
