# UE Shed 0.30.0

UE Shed 0.30.0 adds two things. The Project Index now records which packages each package depends
on. Game Text now reports text that points at a String Table entry that doesn't exist. All 21
public npm packages and twelve Unreal plugins advance together. Packages with no direct changes
advance so the suite stays aligned and the exact dependency pins match.

## Project Index

- The index records each package's dependencies the way Unreal's Asset Registry does. Hard, game
  and build edges are read from the package header, with the same rules for engine packages,
  self-references and external actors.
- Two new queries walk those edges: `Dependencies` (what packages need) and `Dependents` (what uses
  them, optionally filtered by export class).
    - Both can follow edges transitively, and both can be limited to game or hard edges.
    - `projectIndexDependencyClosures` splits one page of results into a closure per root.
    - One package's dependencies always fit on a single dictionary page.
- A refresh can report which paths changed or disappeared since the previous generation
  (`changes: true`).
- `plugins: true` builds a separate catalog that also indexes content plugins, so a dependency on
  plugin content resolves.

## Game Text

- A new quality check, `string_table_entry_missing`, reports text that references an entry missing
  from a known String Table. It names the table and the key, so the entry can be added or the
  reference pointed at one that exists.
    - A table defined in code counts as known.
    - References to tables outside the scan aren't reported, since they may resolve in engine or
      plugin content.
- Unreal saves a String Table reference without its source text, so a reference to a missing entry
  used to be hidden from the Text tab and Quality. Its line and places now stay visible. The line
  takes its places' origin and audience, so the Text tab's filters find it.

## Compatibility

Use matching 0.30.0 packages and plugin sources. Each public package's Node requirement is
unchanged. The repository's release tooling uses Node 26.

- **Index formats change, so expect one rebuild of each after upgrading:**
    - The Project Index catalog moves to `catalogs-v7`; the first refresh rebuilds it.
    - Game Text's joined index moves to `joined-native-v10`; each target rebuilds it once.
- The dependency queries and the plugin catalog need uasset-io v1.23, which this release ships.
