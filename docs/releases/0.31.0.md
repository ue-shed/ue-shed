# UE Shed 0.31.0

UE Shed 0.31.0 lets a host read a saved package's header from only the start of the file. All 21
public npm packages and twelve Unreal plugins advance together. Packages with no direct changes
advance so the suite stays aligned and the exact dependency pins match.

## Saved package headers from leading bytes

- `readSavedPackageHeader` in `@ue-shed/unreal-assets` reads one package's header from a file
  holding only the package's first bytes, given the size of the whole package. A host reading a
  revision from a version-control server can learn its exports and their classes without
  downloading a file that may be hundreds of MB.
    - The result is the `SavedAssetHeader` a header-depth scan gives for the whole file: each
      export with its class name and class path, and the package facts.
    - The package name and object paths come from the package's own summary, as in a scan.
      `packagePath` names the package in `path`; without it, `path` is the file of leading bytes.
- When the file ends before the header does, the read fails with `PackageHeaderNeedsBytes`.
  Its `requiredBytes` is how many leading bytes to supply next: the 64 KiB summary window until
  the summary is readable, then the exact header size. A host reaches the header in at most three
  reads.
- A package size that is not positive, or is smaller than the file, fails as an `AssetReaderError`
  of the new kind `invalid_input`, not as malformed data.
- Scans and other reads of files on disk are unchanged: a file that really is truncated still fails
  as malformed.

## Compatibility

Use matching 0.31.0 packages and plugin sources. Each public package's Node requirement is
unchanged. The repository's release tooling uses Node 26.

- The leading-bytes read needs uasset-io v1.24 and its new `package_header` operation, which this
  release's native reader ships. An older reader rejects the operation.
- `AssetReaderError` gains the `invalid_input` kind. Code that switches over every `kind` needs a
  case for it.
- No index or cache format changes; existing Project Index and Game Text indexes stay valid.
