# UE Shed 0.32.0

UE Shed 0.32.0 lets a host change the limits that stopped big maps, big projects, slow editors and
long Unreal jobs. Limits that dropped data silently now say so. All 21 public npm packages and twelve
Unreal plugins advance together. Packages with no direct changes advance so the suite stays aligned
and the exact dependency pins match.

## Captures on slow editors

- A long high-resolution capture no longer fails because one frame status check got no answer
  within 30 seconds while Unreal rendered the shot. Checks that time out are sent again until the
  frame's deadline; a frame past its deadline fails as `settling_timeout`.
  `CameraRendererOptions` (`requestTimeout`, `frameDeadlineMargin`) set both.
- Lease renewal survives a slow renderer call; only a lease that really runs out fails, as
  `lease_expired`. Map tile polls retry the same way, and `runMapCapture` takes `batchDeadline`.
- Map capture 1.3 adds `render.timing` (`frameTimeoutMs`, `settleFrames`, `overviewFrames`,
  `screenshotWarmupFrames`) to plans and requests, replacing the plugin's fixed values.
- Captures can switch volumetric clouds off: `clouds` on both renderer policies, advertised in
  `GetCameraRenderCapabilitiesV2`, and `render.effects.clouds` in map capture 1.3.

## Remote Control timeouts the host controls

- `makeRemoteControlClient` takes a `minimumTimeout` floor and exact `operationTimeouts`;
  `RemoteControlClientLive` reads the floor from `UE_SHED_REMOTE_CONTROL_MINIMUM_TIMEOUT`.
  `captureReviewSet` and `runMapCapture` honour the environment instead of fixed clients.
- `@ue-shed/unreal-connection` calls send stable operation names such as `unreal.authoring.apply`
  and `unreal.producer.inspect`, so a host can give one slow call more time.

## Long Unreal processes

- Game Text localization steps take `timeoutSeconds` from the operations host.
- The localization commandlet log cap is `logLimits.maxBytes` on `makeLocalizationOperationsLayer`.
- `runNiagaraPreview` takes `commandletTimeoutMs` and `sessionTimeoutMs`; a session timeout fails as
  `process_timeout`.
- Supervised editor readiness, polling and termination accept up to 24 hours.

## Big maps and projects

- The observatory catalog reports `omittedActors` past 16,384 actors.
- World preparation counts up to 4,000,000 actor descriptors and loaded actors (was 100,000).
- Camera render requests may be 4 MiB; an oversize one says its size and the limit.
- Actor reference scans take `maxPropertyVisits`.
- Game Text groups page past 200 with `groupOffset`.
- A Project Index refresh reports `total` changes when cut, `maximumChanges` raises the cut
  (uasset-io v1.25), and `omittedDiagnostics` counts dropped diagnostics.
- Map History warns `map_lineage_may_be_incomplete` when filelog fills its window, with
  `limits.maxFilelogRevisions` and `limits.maxDirectMapMoves`.

## Big data

- Game Text baselines take `baselineLimits` (`maxEntries`, `maxFileBytes`); the file default rises
  to 64 MiB so the 100,000-entry default is reachable.
- WASM inspection `maxInputBytes` and `maxOutputBytes` can be raised to 512 MiB.
- The plugin cache waits up to `lockWait` (default 10 minutes) for a live lock holder.
- Authoring Apply limits come from `[UEShed.Authoring]` in the project's editor config, read by
  both the capability manifest and Apply.
- Authoring analysis no longer overflows the stack on tables over about 100,000 rows.

## Compatibility

Use matching 0.32.0 packages and plugin sources. Each public package's Node requirement is
unchanged.

- Map capture plans using `clouds` or `render.timing` need contract 1.3 and 0.32.0 plugins; older
  plugins refuse them. Plans without them keep working with older plugins.
- `UnrealConnectionError.operation` carries the new operation names. Code matching
  `remote_control.GetCapabilityManifest` should match `unreal.producer.inspect`.
- `LocalizationBaseline` no longer bounds `entries` in its schema; the creating and decoding
  functions take `LocalizationBaselineLimits`.
- Project Index `maximumChanges` and the new response fields need uasset-io v1.25, which this
  release's native reader ships.
- No index or cache format changes.
