# UE Shed 0.33.1

UE Shed 0.33.1 eliminates the dominant cold-build bottlenecks in Project Index refreshes on Windows
and large catalogs without changing the cache format, wire protocol, or query output. All 21 public
npm packages and twelve Unreal plugins advance together. Packages with no direct changes advance so
the suite stays aligned and the exact dependency pins match.

## Project Index: faster cold builds on Windows and large catalogs

- **No-atime file reads and handle signatures on Windows**: Package header reads and whole-file
  asset reads open files with `FILE_WRITE_ATTRIBUTES` (falling back to `File::open` on any refusal,
  including read-only volumes, restricted ACLs, or SMB shares with access-based enumeration) and
  suppress NTFS `LastAccessTime` updates on the handle. This eliminates per-file MFT metadata writes
  and NTFS change-journal churn during cold walks while leaving file access times untouched. Header
  observations also read file size and modification time directly from the open handle via
  `GetFileInformationByHandleEx` and avoid redundant relative-path normalization.
- **64 KiB `NtQueryDirectoryFile` discovery on Windows**: Content directory enumeration streams
  `FileFullDirectoryInformation` batches through a recursion-safe thread-local 64 KiB buffer,
  preserving exact `read_dir` symlink/junction classification, `\\?\` long-path support, and error
  codes.
- **Parallel catalog postings build and directory encoding**: Large catalog commits (≥4,096 rows and
  ≥16,384 posting entries) build class, serialized-name, and dependency postings in parallel across
  balanced key ranges with per-batch scratch memory released between batches, and encode posting
  directories (≥65,536 keys) in parallel with stack-buffered varint encoding.
- **Measured impact**: On a project of about 783,000 packages (~242,000 directories, 181.7 MB
  Catalog) on Windows 11:
    - Cold-atime header reading drops from about 26.2 s to about 7.0 s (`3.77×`), with header worker
      processing dropping from about 21.8 s to about 3.0 s (`7.15×`), and zero `LastAccessTime` or
      USN journal writes.
    - Warm-cache catalog commit time drops by about 21% (from about 1.93 s to about 1.53 s), and warm
      directory enumeration drops by about 8–9% (from about 1.21 s to about 1.12 s on cold builds and
      from about 1.19 s to about 1.08 s on warm no-op walks).
    - Output is byte-identical (`cacheBytes` and all six candidate set SHA-256 digests match).

## Compatibility

Use matching 0.33.1 packages and plugin sources. Each public package's Node requirement is
unchanged.

- Project Index cache format (`catalogs-v10`), uasset-io wire protocol (v1.27), Game Text snapshot
  format (`UESHT004`), and Unreal plugin wire contracts are all unchanged from 0.33.0.
- Existing `catalogs-v10` caches and `UESHT004` snapshots are reused directly with no rebuild
  required.
