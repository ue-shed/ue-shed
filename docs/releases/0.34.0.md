# UE Shed 0.34.0

UE Shed 0.34.0 makes camera and map viewport captures sharp when the editor runs in the background
and adds an `offscreen_viewport` strategy that draws each frame at the requested output size. All 21
public npm packages and twelve Unreal plugins advance together. Packages with no direct changes
advance so the suite stays aligned and the exact dependency pins match.

## Cameras: sharp background captures and the `offscreen_viewport` strategy

- **Temporal anti-aliasing in a background editor**: An unfocused or throttled editor drew every
  capture frame as non-realtime, which dropped TSR/TAA to FXAA: foliage came out speckled, thin
  geometry broke up and edges were jagged. The render session now marks only its own frames realtime
  and lifts Slate throttling while it draws. It also no longer redraws the live viewport between
  capture frames, which reset TSR history and restarted settling. The editor no longer throttles its
  CPU while a render session is open, and a finished PNG's size is read from its header instead of
  decoding the whole image.
- **`offscreen_viewport` strategy**: The viewport renderer can draw the locked camera into an
  offscreen target of the requested size on every settling frame, so temporal anti-aliasing builds
  up at output size. The PNG is written off the game thread. Frames render at 100% screen percentage
  without low-DPI scaling, set on the capture's own view family, so the live viewport keeps its
  settings. The strategy takes `resolution: "native"` and `lod: "highest" | "natural"`. `highest`
  draws meshes with discrete LODs at LOD 0 for that view only, without changing any console variable;
  Nanite meshes keep choosing their own detail.
- **Discovery**: Plugins advertise the strategy through `GetCameraRenderCapabilitiesV3`
  (`cameras.render-session.capabilities.v3`). The SDK prefers v3, falls back to v2 and v1, and
  refuses `offscreen_viewport` as `unsupported_capability` before acquiring an editor whose plugin
  lacks it.
- **Captures interrupted by an unpilot**: When the user unpilots the capture camera mid-capture, the
  session fails with `world_changed`. It leaves the viewport to the user and returns the realtime
  override and input it took.
- **Measured impact**: Steady-state captures of a World Partition map in UE 5.8.2 with TSR and 16
  settling frames take about 5.3 s at 4K, 2.2 s at 2K and 1.7 s at 1K.

## Compatibility

Use matching 0.34.0 packages and plugin sources. Each public package's Node requirement is
unchanged.

- `CameraRenderCapabilities` in `@ue-shed/cameras` is now the v3 shape. The v2 shape is exported as
  `CameraRenderCapabilitiesV2`.
- The v1 and v2 capability responses and the render request contract (1.0) are unchanged. Plugins
  older than 0.34.0 keep working with every existing strategy, and the SDK refuses only
  `offscreen_viewport` on them.
- Project Index cache format (`catalogs-v10`), uasset-io wire protocol (v1.27) and Game Text
  snapshot format (`UESHT004`) are unchanged from 0.33.1.
