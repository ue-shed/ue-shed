# UE Shed 0.34.1

UE Shed 0.34.1 lets camera authoring and captures leave out most kinds of actor, not only opaque
static meshes. All 21 public npm packages and twelve Unreal plugins advance together. Packages with
no direct changes advance so the suite stays aligned and the exact dependency pins match.

## Cameras: hidden actors are left out with everything they draw

- **More kinds of actor can be hidden**: A hidden actor is left out with every component it draws
  and the child actors its components spawned. That covers static, instanced and skeletal meshes,
  with opaque, masked or translucent materials. Before, one component of any other kind made the
  whole actor unsupported: a collision shape or an editor icon was enough, so most Blueprint
  actors, trees with masked leaves and anything with a translucent material could not be hidden.
- **Still refused**: Nanite meshes and terrain, which no pixel proof covers yet, and an actor that
  draws nothing, since there is nothing to leave out. Each refusal's diagnostic says which, and the
  camera panel's message names them.
- **Why this is safe**: A view hides a component by its primitive scene ID before the renderer
  considers the component's kind or material, and shadow setup skips the same IDs; a SceneCapture's
  hidden actors expand to all their primitive components the same way. The visibility proof draws
  each kind visible, hidden and visible again through both the viewport and SceneCapture on UE 5.7
  and 5.8, with the masked and translucent proof materials compiled before drawing and checked to
  draw in their own colour.

## Compatibility

Use matching 0.34.1 packages and plugin sources. Each public package's Node requirement is
unchanged.

- The `authoredVisibility.geometry` capability still reports
  `loaded_non_nanite_opaque_static_mesh_actors`, so strict clients of the v1, v2 and v3 capability
  responses are unaffected. It names the first proven scope; to learn whether a particular actor
  can be hidden, ask preflight.
- Camera render, review capture and authoring wire contracts are otherwise unchanged from 0.34.0.
