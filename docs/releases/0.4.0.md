# UE Shed 0.4.0

UE Shed 0.4.0 adds Niagara Preview as the sixteenth public npm package and advances the complete
public suite to 0.4.0. This is a direct stable release; packages without a direct behavioral change
advance for suite alignment and exact internal dependency pins.

## Highlights

- New `@ue-shed/niagara` turns one saved `UNiagaraSystem` into an immutable, portable PNG frame
  sequence. The headless workflow supervises Unreal, validates contained producer output, hashes
  every frame, and atomically publishes only complete runs.
- The separately enabled, Editor-only `UEShedNiagara` plugin captures in an isolated preview scene
  using the system's saved Baker camera and deterministic desired-age timing. Component-only output
  is the default; full preview-scene output is explicit.
- `ue-shed niagara preview` exposes the same workflow through the CLI. The package also provides a
  browser-safe entry point for request, manifest, artifact, and typed failure contracts.
- The private Workbench showcase at `#/niagara-preview` can capture and loop completed sequences
  with play, pause, restart, and timeline controls. Workbench and its extension remain dogfood
  clients and are not part of the published package suite.

## Compatibility notes

- Niagara Preview currently requires Unreal Engine 5.7 and a separately installed or staged
  `UEShedNiagara` plugin. The public npm package requires Node.js 22.14 or newer.
- The producer request, receipt, and published manifest introduce version 1.0 contracts. This is an
  additive package and does not change an existing wire contract.
- Deterministic simulation timing does not promise pixel-identical output across GPUs, drivers,
  render settings, or engine builds.
- Isolated preview capture does not claim parity for map depth, collision, distance fields,
  Blueprint or gameplay drivers, or externally supplied user parameters.

## Package scope

`@ue-shed/niagara` is newly public in 0.4.0. The other 15 public npm packages advance to 0.4.0 for
synchronized suite alignment or exact dependency pins. Workbench and the Workbench extension stay
private and are not release artifacts.

## Release evidence

The versioned release tree passes the complete portable gate, including contract parity, native
tests, and all 16 packed npm tarballs installed into a clean offline consumer. The trusted local
`pnpm check:unreal` gate also passes on Unreal Engine 5.7.4, including Niagara conformance with two
captured and hashed frames plus the existing UAsset, authoring, durable capture, and live Workbench
journeys.

The synchronized suite is prepared for direct stable publication as 0.4.0 under npm's `latest`
tag, with no release-candidate step. This preparation does not itself publish, tag, or announce the
release.
