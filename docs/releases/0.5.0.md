# UE Shed 0.5.0

UE Shed 0.5.0 adds exact compiled Unreal Editor plugin variants to the public plugin-distribution
contract. Trusted hosts can acquire compatible binaries without allowing capture or Runner
processes to invoke a C++ toolchain, while downstream studios retain ownership of proprietary
engine builds and private artifact infrastructure.

## Highlights

- `@ue-shed/plugin-distribution` now models source and compiled artifacts as versioned,
  discriminated contracts. A compiled variant pins the Unreal version and exact engine BuildId,
  platform, architecture, target, configuration, toolchain, plugin graph and descriptor versions,
  source provenance, build provenance, and manifest and archive digests.
- Binary selection is exact. A compiled request never falls back to source, and source acquisition
  remains explicit. Missing compatibility produces an actionable typed failure before extraction or
  editor launch.
- The cache derives immutable `pv2-...` identities from validated compatibility and pinned artifact
  identity. Source and multiple stock or custom-engine variants can coexist for one UE Shed release;
  leases and pruning address one exact variant.
- `ue-shed plugins build` separately supervises Unreal's `RunUAT BuildPlugin` workflow, validates the
  complete dependency graph and `.modules` BuildId evidence, and atomically publishes a versioned
  manifest and archive beneath a caller-owned output directory. Acquisition never compiles.
- Local directories, immutable HTTP endpoints, GitHub Releases, and downstream registry adapters
  remain transport seams. Registry layout and asset naming do not enter the domain model.

## Compatibility notes

- Unreal version `5.7` alone is not binary compatibility. Consumers must request the exact engine
  BuildId plus platform, architecture, `UnrealEditor` target, and `Development` configuration.
- Existing 0.4.0 source manifests and source-only cache entries remain supported. The immutable
  0.4.0 release is not retrofitted with binaries; binary requests require a real 0.5.0-or-later
  compiled manifest.
- UE Shed publishes portable source contracts and may publish binaries built against a stock Epic
  engine. A downstream studio compiles against its proprietary engine, signs and hosts those
  artifacts privately, and owns access and retention policy. Custom-engine artifacts are not public
  UE Shed release assets.
- Compiler output is not claimed to be byte reproducible. Determinism covers semantic metadata,
  canonical manifests and digests, exact selection, and immutable publication.

## Package scope

`@ue-shed/plugin-distribution` receives the direct minor change. The other 16 public npm packages
advance to 0.5.0 for synchronized suite alignment and exact internal dependency pins. Workbench and
its extensions remain private dogfood clients and are not npm release artifacts.

## Release evidence

The versioned release tree passes the complete portable gate, including native and architecture
checks plus all 17 packed npm tarballs installed into a clean offline consumer. The trusted local
`pnpm check:unreal` gate also passes on Epic Unreal Engine 5.7.4 (BuildId `47537391`), including
external Core and Cameras descriptors, UAsset conformance, live authoring mutation, Niagara
conformance with two captured and hashed frames, 15 live review tests, and all five process-level
Map Review journeys.

The synchronized suite is prepared for direct stable publication as 0.5.0 under npm's `latest`
tag. This preparation does not publish packages, create a Git tag, or create a GitHub Release.
