# UE Shed 0.5.1

UE Shed 0.5.1 is an immutable corrective source release for Review Capture and downstream Unreal
plugin builds. It keeps UE Shed engine- and studio-agnostic: public artifacts contain portable
plugin source, while consumers compile and register exact variants for their own Unreal builds.
The existing 0.5.0 packages and artifacts remain untouched.

## Highlights

- Review Capture 1.5 now has one matching TypeScript, JSON Schema, fixture, and Unreal C++ contract.
  Capture operation IDs are exact non-nil UUIDs. Actor subjects use Unreal's exact
  `FGuid::UniqueObjectGuid` spelling, with bounded optional path and diagnostic evidence.
- Review Views retain durable authored actor GUIDs. `UEShedCameras` resolves actor subjects by GUID,
  reports the resolved GUID and current actor path, and initializes revision authoring from the
  persisted camera pose.
- Unreal accepts complete compatible Review Capture 1.x requests through minor 5 and rejects future,
  contradictory, or malformed requests deterministically. Once an operation ID has been read, it is
  retained in failure results.
- Schema-v3 source artifacts bind the portable plugin graph, npm tarballs, Review Capture contract,
  and repository commit. Publication requires the clean source commit to remain unchanged across
  validation and confirmation.
- The generic `ue-shed plugins build` workflow compiles a selected dependency graph against an
  explicit caller-supplied engine root. Compiled variants pin the exact Unreal version, engine
  BuildId, platform, architecture, source manifest and archive, plugin graph, native files, and
  content digests.
- Cold-cache extraction derives module identity from the archive's `.modules` files and requires an
  exact match with every schema-v3 module attestation before publishing the immutable cache entry.

## Downstream plugin builds

The portable Map Review source graph contains `UEShedCore` and `UEShedCameras`. Acquire and pin the
0.5.1 source pair:

- `ue-shed-plugins-map-review-0.5.1.manifest.json`
- `ue-shed-plugins-map-review-0.5.1.tar.gz`

Then run the generic builder with the consumer's engine identity:

```powershell
ue-shed plugins build `
  --engine C:\Engines\UE_5.7-Custom `
  --source-manifest C:\input\ue-shed-plugins-map-review-0.5.1.manifest.json `
  --source-artifact C:\input\ue-shed-plugins-map-review-0.5.1.tar.gz `
  --source-manifest-digest sha256:<manifest> `
  --source-artifact-digest sha256:<archive> `
  --output C:\build-output\ue-shed-plugins `
  --plugin UEShedCameras `
  --unreal <exact-version> --build-id <exact-build-id> `
  --platform Win64 --architecture x64 `
  --compiler MSVC --compiler-version <version> `
  --toolchain "Visual Studio" --toolchain-version <version>
```

The consumer owns its build worker, private engine, signing, registry adapter, credentials, and
retention policy. No private engine path, project identity, or registry configuration is part of UE
Shed's public release.

## Compatibility notes

- Replace 0.5.0 package and source-artifact pins as one synchronized update; do not combine a 0.5.1
  npm package with a 0.5.0 plugin artifact.
- Compiled selection remains exact. A wrong Unreal version, BuildId, platform, architecture, source
  digest, archive digest, or contract fails closed and never falls back to source.
- Schema-v1 source and schema-v2 source/compiled manifests remain readable for existing immutable
  releases. New 0.5.1 release artifacts use schema version 3.
- Public UE Shed does not publish or endorse binaries for private engine forks. Stock-engine binaries,
  if published separately, must carry their own exact engine identity and remain distinguishable
  from consumer-built variants.

## Package scope

`@ue-shed/cameras`, `@ue-shed/protocol`, and `@ue-shed/plugin-distribution` receive direct patch
changes. The other 14 public packages advance to 0.5.1 for synchronized suite alignment and exact
internal dependency pins, with no direct behavioral change. Workbench and its extensions remain
private dogfood clients and are not npm release artifacts.

This preparation does not publish npm packages, create a Git tag, upload an artifact, or create a
GitHub Release.
