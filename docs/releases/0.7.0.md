# UE Shed 0.7.0

UE Shed 0.7.0 adds shared editor-world camera rendering for headless callers, Review, and Map
Capture. This release follows 0.6.0 and advances all 17 public npm packages and seven Unreal plugin
descriptors together.

## Camera rendering

- Render absolute perspective or orthographic cameras with scoped `CameraRenderer.open` sessions
  or one-shot `renderCamera`. The CLI exposes the same workflow through `ue-shed camera render`.
- Select explicit editor-viewport or SceneCapture policies, exposure, bounded settling, geometry
  preparation, and supported scene freezing. Preflight reports blockers before taking ownership;
  unsupported settings fail without an automatic renderer fallback.
- Receive preparation and capture progress, effective rendering policy, restoration results, and
  validated PNG artifact evidence. Scoped ownership restores editor state on completion or
  cancellation, and artifact publication follows successful restoration.

## Review and Map Capture

- Review previews and final captures share the rendering lifecycle and selected policy. Fixed
  Review cameras use their saved pose even when the actor is unavailable, retaining provenance and
  explicit unassessed visibility. Actor-relative views still require their actor.
- Existing map modes use shared rendering while retaining their distinct algorithms, including Lit
  overview warmup, per-frame settling, shared exposure, and owned scene freezing.
- Map responses negotiate rendering evidence with capable plugins and retain wire 1.0 compatibility
  with released plugins. Shared-renderer plugins must explicitly report successful restoration.

## Upgrade notes

- Install the matching 0.7.0 UEShedCore/UEShedCameras bundle for shared rendering and negotiate
  `cameras.render-session.v1`. Released 0.6.0 plugins do not expose this capability.
- Review Set 1.3 adds `CaptureProfile.renderPolicy`; Capture Run and capture wire 1.6 record the
  shared rendering evidence. Existing Review documents retain their historical SceneCapture
  policy, and legacy capture wire 1.0–1.5 remains supported.
- Map manifest 1.1 records source-render policy and evidence separately from derived tile dimensions.
- Rendering requires an editor world with Play and Simulate stopped. Viewport rendering supports
  Natural Review captures but does not support depth assessment or Clear. SceneCapture does not
  support meter-once exposure; saved Review pose documents remain perspective-only.
- Settling frame counts do not prove visual convergence. Native staging is temporary; consume
  artifacts promptly and publish them to caller-owned storage after successful restoration.
- Public packages retain their declared Node.js 22.14 minimum; repository builds use Node.js 26.
- Packages other than cameras and protocol advance for suite alignment and internal dependency
  updates, with no direct behavioral changes in this release.

## Release preparation

The release source is based on `673b2c8`, compared with tag `v0.6.0`. Publication requires a reviewed,
clean release commit, the portable `pnpm check` gate, and trusted `pnpm check:unreal` evidence because
this release changes Unreal camera behavior and plugin artifacts. Source bundles and compiled
variants must be bound to that exact release commit; preparation alone does not publish artifacts.

Preparation validation passed release/version tests, contract checks, formatting, 157 targeted
camera/CLI tests, and public-package conformance for all 17 tarballs in a clean offline consumer.
`pnpm check:unreal` also passed, including saved-asset conformance, authoring, Niagara, 22 live
Review/map tests, and five end-to-end Map Review flows.
The package check used pnpm 11.17.0 throughout: the installed launcher otherwise selected pnpm
12.3.4 in temporary directories, producing a different tar entry order and failing byte parity.
The full portable `pnpm check` gate remains required before publication.

See [shared camera rendering](../products/camera-rendering.md) for the API and capability limits,
and [the release procedure](../engineering/releases.md) for packing, evidence, and publication.
