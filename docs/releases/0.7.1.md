# UE Shed 0.7.1

UE Shed 0.7.1 fixes native plugin compilation on Unreal Engine 5.8 while retaining 5.7 support.
Unreal 5.8 stores JSON object keys as `UE::FSharedString`; 0.7.0 assumed `FString` in camera request
validation and Authoring canonical JSON, causing compiler errors before plugins could load.

## Changes

- Camera render and Review request validation accepts the engine's JSON key storage type while
  preserving the existing allowed-field checks.
- Authoring copies keys into owned strings for deterministic sorting and uses the JSON field API
  for value lookup. Native regression coverage checks key ordering, null values, and nested sets.
- Default source bundles and release candidates declare Unreal 5.7 through 5.8.2 support. Explicit
  engine ranges remain supported.
- `pnpm test:unreal-plugins <new-evidence-directory>` builds all seven plugins against
  `UE_SHED_UNREAL_ENGINE_ROOT` and verifies rendered camera/map behavior, screenshot ownership,
  Niagara, and Authoring in a disposable project.

## Compatibility

Use 0.7.1 source artifacts to build native plugins for Unreal 5.8. Existing 0.7.0 artifacts remain
unchanged. Compiled variants still require the exact engine version, BuildId, platform, and
architecture; a stock 5.8.2 binary does not match a custom 5.8.2 engine automatically.

The saved-asset parser and its fixture support window are unchanged. This release extends native
plugin compatibility, not saved-package format claims.

`@ue-shed/cameras` and `@ue-shed/plugin-distribution` receive direct patch changes. The other 15
public packages advance to 0.7.1 for suite alignment and exact internal dependencies, with no direct
behavioral changes.

## Validation

All seven plugins compile against stock Unreal 5.7.4 and 5.8.2, and all five native compatibility
tests pass on each engine. The exact Map Review `BuildPlugin` workflow also succeeds against a
custom 5.8.2 engine, including compiled archive and manifest verification.
That compiled artifact also passes all three camera rendering, screenshot ownership, and map
compatibility tests in a disposable project on the custom engine.

The full `pnpm check` gate passes, including 188 test files / 1,154 tests and packed-consumer
conformance for all 17 npm packages. `pnpm check:unreal` passes saved-asset conformance, Authoring
mutation, Niagara, 22 live Review/map tests, and five Workbench flows.
