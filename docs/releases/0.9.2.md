# UE Shed 0.9.2

UE Shed 0.9.2 fixes compiled plugin archives with long paths and discovers Launcher engines
installed outside Program Files. All 19 public npm packages and ten Unreal plugins advance to
0.9.2 together; packages without direct changes advance for suite alignment and exact dependencies.

## Compiled plugin archives accept long paths

- Compiled plugin archives now split long paths between the ustar prefix and name fields at a
  slash that fits both fields, measured in bytes. Paths over 100 bytes, including camera-authoring
  panel source paths, no longer fail with "Archive path is too long" when a valid split exists.

## Engine discovery finds custom Launcher installations

- Engine discovery reads the Epic Games Launcher's `LauncherInstalled.dat` to find engines
  installed outside Program Files, alongside the existing discovery sources.

## Upgrade notes

There are no breaking changes. Use matching 0.9.2 packages for suite alignment. Native plugin
behavior is unchanged from 0.9.1.

Native plugin compatibility targets Unreal 5.7 and 5.8. Compiled variants require matching engine
version, BuildId, platform and architecture.

## Validation

Release preparation on 2026-10-06 uses Node 26.10.0 and pnpm 11.17.0.

- Portable gate (`pnpm check`): passed, 1,550 tests passed and 50 explicitly gated tests skipped;
  all 19 packed packages passed clean offline consumer conformance.
- Data Authoring adoption conformance passed after including the shared package-build cleanup
  helper in its copy manifest: the exported app built, theme divergence changed production CSS,
  and the copied host discovered 12 fixture DataTables and opened a saved table.
- Trusted Unreal checks on UE 5.7 and UE 5.8 are omitted for this portable-only patch: the fixes
  change archive packaging and local engine discovery, with no Unreal behavior or native plugin
  changes.
