# Config Explorer extension

This host-neutral Solid/StyleX extension renders browser-safe Config Explorer explanations and
platform comparisons supplied through component props. It has no filesystem, process, Electron,
Unreal, or Workbench IPC authority.

The route intentionally labels every result as saved-source evidence rather than live runtime
state. Its contribution timeline, layer ledger, and authority ledger keep missing, unreadable,
unsupported, and deliberately excluded evidence visible.
