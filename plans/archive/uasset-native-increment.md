# Native parser increment

Implement the approved first three additions for UE 5.7 and UE 5.8 classic uncooked packages.

- [x] Project saved scalar and transform Sequencer channels, with explicit partial coverage.
- [x] Decode GameplayTagContainer through source-checked native layouts.
- [x] Decode Quat, Transform, Vector2D, Box, and IntVector in properties, containers, and InstancedStruct.
- [x] Extend Unreal fixtures and independent fresh-process semantic evidence.
- [x] Verify malformed inputs, public contracts, native/WASM parity, and the full local gate.

Keep saved values independent of runtime evaluation, gameplay-tag redirects, and authoring.
Unknown native payloads remain explicit. Engine source is a development input only.

Transform properties and instances use tagged framing in UE 5.7 and UE 5.8; their nested native quaternion
now decodes. A source-derived native Transform archive layout is distinct from that property path.
Level Sequence records advance to schema 4 and publish their JSON Schema with the WASM package.

The fixture was built and generated in an ignored isolated copy because an existing editor held the
normal fixture DLLs open. A second Unreal commandlet process reloaded the saved assets and emitted
independent semantic evidence. Both source models passed freshness checks against the installed
UE 5.7 source. No running user editor was closed or reloaded.

Completed 2026-09-29. `pnpm check` passed on Node 26.9.0, including Rust/Clippy, native/WASM
conformance, browser and packed-package checks, TypeScript, architecture, contracts, and copied
Data Authoring adoption. The final test stage passed 1,289 tests with 50 explicit opt-in skips.
The seven native coverage tests also passed directly against fresh Unreal API evidence. Malformed
coverage includes truncation, invalid counts/names/box flags, versions, empty/default channels,
nonfinite values, mismatched channel lengths, and missing channels/masks. Full live-editor and
Perforce suites were not enabled.

The follow-up dual-engine gate, `pnpm test:uasset-engine-matrix`, passed on UE 5.7.4 and UE 5.8.2.
It checks source-derived native layout equivalence, builds isolated fixtures, saves native assets,
reloads each engine's assets in a fresh process, and compares Rust semantic output and native/WASM
output with that engine's evidence. Fixture build settings, string-table API calls, and a constant
name were adjusted for 5.8 compilation. The test runner accepts an explicit fixture root so 5.8
checks read 5.8-generated bytes. Both versions are now required by AGENTS.md and the parser skill.
